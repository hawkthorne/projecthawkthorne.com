This 2d platformer is based on Community's [Digital Estate Planning](http://en.wikipedia.org/wiki/Digital_Estate_Planning) episode. It's built using the [LÖVE](https://love2d.org) game engine. Please [report any issues or bugs](https://github.com/hawkthorne/hawkthorne-journey/issues) you have with the game!

## Development

All discussion and development takes place on [/r/hawkthorne](http://www.reddit.com/r/hawkthorne). If you have any contributions you'd like to submit, either open a pull request or create a post on the subreddit.

## Downloads

- [Windows](https://github.com/hawkthorne/hawkthorne-journey/releases/download/v1.0.4/hawkthorne-win-x86.zip)
- [macOS](https://github.com/hawkthorne/hawkthorne-journey/releases/download/v1.0.4/hawkthorne-osx.zip)

Linux users: Install [LÖVE](https://love2d.org). You'll need at least version 11.3. After installing LÖVE, download the [.love file](https://github.com/hawkthorne/hawkthorne-journey/releases/download/v1.0.4/hawkthorne.love) and run it. Everyone gets to play!
